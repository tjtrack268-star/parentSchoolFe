# Guide de Déploiement Parents School\n\n## 📋 Prérequis\n\n- Node.js 18+\n- Compte Supabase\n- Compte Vercel (ou autre plateforme de déploiement)\n- Git\n\n## 🚀 Étapes de Déploiement\n\n### 1. Préparation Locale\n\n```bash\n# Cloner le projet\ngit clone <your-repo-url>\ncd schoolParent\n\n# Installer les dépendances\nnpm install\n\n# Tester localement\nnpm run dev\n# Visiter http://localhost:3000\n```\n\n### 2. Configurer Supabase\n\n#### 2.1 Créer un projet Supabase\n1. Aller sur [supabase.com](https://supabase.com)\n2. Cliquer \"New Project\"\n3. Remplir les détails du projet\n4. Attendre la création (~2 minutes)\n\n#### 2.2 Récupérer les clés\n1. Aller dans Settings > API\n2. Copier:\n   - Project URL\n   - Anon Key (public)\n   - Service Role Key (secret)\n\n#### 2.3 Initialiser la base de données\n1. Aller dans SQL Editor dans Supabase\n2. Exécuter les scripts SQL dans cet ordre:\n   ```sql\n   -- 1. Copier contenu de scripts/001_create_tables.sql\n   -- 2. Copier contenu de scripts/002_rls_policies.sql\n   -- 3. Copier contenu de scripts/003_triggers_functions.sql\n   -- 4. Copier contenu de scripts/004_seed_grades.sql\n   -- 5. Copier contenu de scripts/005_career_functions.sql\n   -- 6. Copier contenu de scripts/006_mlm_triggers.sql\n   ```\n\n#### 2.4 Activer l'authentification par email\n1. Aller dans Authentication > Providers\n2. Vérifier que \"Email\" est activé\n3. Configurer les emails si nécessaire\n\n### 3. Configurer les Variables d'Environnement\n\n```bash\n# Copier le template\ncp .env.local.example .env.local\n\n# Remplir .env.local\nNEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co\nNEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key\nNEXT_PUBLIC_APP_URL=https://your-app.vercel.app\n```\n\n### 4. Déployer sur Vercel\n\n#### 4.1 Via GitHub (Recommandé)\n\n1. Pousser le code sur GitHub:\n   ```bash\n   git add .\n   git commit -m \"Initial commit: Parents School v1.0\"\n   git push origin main\n   ```\n\n2. Sur [vercel.com](https://vercel.com):\n   - Cliquer \"Import Project\"\n   - Sélectionner le repository GitHub\n   - Vercel configure automatiquement\n   - Ajouter les variables d'environnement:\n     - `NEXT_PUBLIC_SUPABASE_URL`\n     - `NEXT_PUBLIC_SUPABASE_ANON_KEY`\n   - Cliquer \"Deploy\"\n\n#### 4.2 Via CLI Vercel\n\n```bash\n# Installer Vercel CLI\nnpm install -g vercel\n\n# Déployer\nvercel\n\n# Ajouter variables d'environnement\nvercel env add NEXT_PUBLIC_SUPABASE_URL\nvercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY\n\n# Redéployer\nvercel --prod\n```\n\n### 5. Configuration Post-Déploiement\n\n#### 5.1 URL de Redirection d'Authentification\nDans Supabase > Authentication > URL Configuration:\n- Site URL: `https://your-app.vercel.app`\n- Redirect URLs:\n  ```\n  https://your-app.vercel.app/auth/callback\n  https://your-app.vercel.app/dashboard\n  ```\n\n#### 5.2 CORS\nDans Supabase > Authentication > Auth Providers > Email:\n- Ajouter le domaine Vercel aux CORS allowed origins\n\n### 6. Tests de Production\n\n```bash\n# 1. Tester la création de compte\n- Aller sur https://your-app.vercel.app\n- Cliquer \"S'inscrire\"\n- Créer un compte test\n- Vérifier l'email\n\n# 2. Tester le dashboard\n- Se connecter\n- Vérifier la page du dashboard\n- Tester la navigation\n\n# 3. Tester les API routes\n- GET /api/dashboard/stats\n- GET /api/dashboard/tree\n```\n\n## 🔒 Sécurité\n\n### Checklist de Sécurité\n\n- [ ] RLS policies activées sur Supabase\n- [ ] Variables d'environnement secrètes configurées\n- [ ] HTTPS activé (Vercel par défaut)\n- [ ] Authentification par email fonctionnelle\n- [ ] Emails de confirmation envoyés\n- [ ] Middleware de protection des routes actif\n- [ ] Rate limiting configuré (si applicable)\n- [ ] Monitoring en place\n\n## 📊 Monitoring\n\n### Supabase\n- Dashboard > Statistics\n- Vérifier les requêtes API\n- Monitorer l'utilisation de la base de données\n\n### Vercel\n- Aller sur le dashboard Vercel\n- Vérifier Analytics > Web Vitals\n- Vérifier les logs\n\n## 🆘 Troubleshooting\n\n### \"Connection refused\"\nVérifier:\n- Variables d'environnement configurées\n- URL Supabase correcte\n- Supabase project est actif\n\n### \"Authentication failed\"\nVérifier:\n- Email provider activé dans Supabase\n- URL de redirection configurée\n- Domaine autorisé\n\n### \"RLS policy violation\"\nVérifier:\n- Les policies SQL sont exécutées\n- L'utilisateur a les permissions correctes\n- Les logs Supabase pour les détails\n\n## 🚀 Mise à Jour\n\n```bash\n# Créer une branche\ngit checkout -b feature/new-feature\n\n# Développer et tester localement\nnpm run dev\n\n# Pousser sur GitHub\ngit push origin feature/new-feature\n\n# Créer une Pull Request\n# Vercel crée automatiquement une preview\n\n# Après review, merger sur main\n# Vercel déploie automatiquement en production\n```\n\n## 📞 Support\n\nPour des questions:\n- Email: support@parentsschool.dev\n- Discord: [Server Link]\n\n## 📝 Notes Importantes\n\n1. **Backups**: Configurer des backups Supabase réguliers\n2. **Scaling**: Vercel scale automatiquement\n3. **Costs**: Surveiller l'utilisation Supabase\n4. **Updates**: Mettre à jour les packages régulièrement\n"
